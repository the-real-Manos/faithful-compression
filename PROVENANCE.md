# Provenance

This public repository is a curated copy of the private repository in which the
study was run. It was created from the private tag `v1.0.1` with the safety
material described in the README's "What this public copy withholds" section
removed or fingerprinted. Everything else is byte-for-byte the private content
at that tag.

The private history is kept, with its original contents and dates, because its
commit order is the evidence that the protocol was written and frozen before the
results it governs. It can be shown on request.
